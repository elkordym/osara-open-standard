# Commit Policy

## Message Format

Use conventional prefixes:

- `spec:`
- `docs:`
- `governance:`
- `chore:`

## Required Rule

Commit messages must not mention specific AI assistant tools or include automated attribution lines.

Examples of disallowed wording:

- "generated by ..."
- "created with ..."
- "authored by Cursor"

## Branch Targeting

- Standard pull requests merge into `prerelease`.
- Only release promotion pull requests merge into `main`.
