# Specification Naming Convention

This project uses a common, predictable convention for specification files:

`<document-slug>-v<major>.<minor>-<stage>.md`

Examples:

- `osara-v0.3-draft.md`
- `ai-bill-of-rights-v1.0-draft.md`
- `osara-v0.4-rc.1.md`
- `osara-v1.0.md`

Stages:

- `draft`
- `rc.N`
- no stage suffix for stable release

Use lowercase kebab-case for all spec filenames.
