# Specification Layout and Naming

## Directory Layout

- `specs/osara/current.md`
- `specs/osara/releases/<version>.md`
- `specs/ai-bill-of-rights/current.md`
- `specs/ai-bill-of-rights/releases/<version>.md`

## Version File Naming

Use:

`v<major>.<minor>-<stage>.md`

Examples:

- `v0.3-draft.1.md`
- `v0.4-rc.1.md`
- `v1.0.md`

`current.md` is the editable working draft. Files under `releases/` are immutable snapshots.
