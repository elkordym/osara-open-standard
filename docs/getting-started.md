# Getting Started

## For Readers

1. Read `specs/osara/current.md`
2. Read `specs/ai-bill-of-rights/current.md`
3. Compare technical and policy alignment via Annex cross-reference sections

## For Contributors

1. Open issue with section reference and rationale
2. Propose exact text in a pull request
3. Link impacts and decision records

## For Implementers

- Treat `MUST` and `SHALL` statements as normative
- Treat explanatory passages as informative context
- Track certification-impacting changes through release tags
