# OSARA Public Comments Register

> Public register of formal comments received against published OSARA Standards Family draft documents, with editor disposition for each comment. Modelled on the W3C "Disposition of Comments" practice.

---

## Purpose

The Public Comments Register provides transparency on how community input received during a public comment period influences the draft. Every formally filed comment is acknowledged and dispositioned before a draft advances to the next maturity stage (e.g., from draft to release-candidate).

This register is maintained per release window. Comments received against `v0.4-draft.1` and `v1.1-draft.1` are recorded below.

## Filing a Comment

Public comments are filed through the repository using the **"Public comment"** issue template (`.github/ISSUE_TEMPLATE/public-comment.md` or its GitLab equivalent). Filers should provide:

- The document and version (e.g., `OSARA v0.4-draft.1`).
- The specific section, requirement ID, or paragraph being commented on.
- The substance of the comment (suggestion, concern, objection, question).
- Whether the commenter is acting on behalf of an organization, and if so which.
- Whether the commenter is willing to be publicly named in the disposition record.

## Disposition Categories

| Category | Meaning |
| --- | --- |
| **Accepted** | The comment is adopted in the current.md draft and will appear in the next release. |
| **Accepted with modification** | The substance is accepted; the wording or scope is adapted by the editors. |
| **Deferred** | Recorded for consideration in a later revision; not addressed in the immediate next release. |
| **Rejected with rationale** | Not adopted; reasoned explanation is recorded. |
| **Out of scope** | The comment addresses a topic outside the document's scope; suggested redirect provided. |
| **Withdrawn** | The commenter has withdrawn the comment. |
