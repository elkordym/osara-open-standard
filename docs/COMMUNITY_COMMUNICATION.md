# Community Communication Model

## Public Channels

- **GitHub Discussions**: high-level ideas, Q&A, proposals
- **GitHub Issues**: actionable change requests and tracked public comments
- **Releases**: official milestone announcements and change summaries

## Cadence

- Weekly triage of new issues/comments
- Monthly community call or written update
- Per-release consultation summary

## Recommended Discussion Categories

- Announcements
- Public Comment Round
- Spec Proposals
- Implementer Feedback
- Governance

## Moderation Principles

- Enforce code of conduct consistently
- Keep technical and policy debates separated by thread
- Always provide rationale for accepted/rejected major proposals
